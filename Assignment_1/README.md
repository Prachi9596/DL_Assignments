# Assignment 1 – TensorFlow/Keras Setup, Data Preprocessing and Visualization

## Aim

Install and configure TensorFlow/Keras in Google Colab. Perform data preprocessing, normalization, train-test splitting, and data visualization on a sample dataset.

## Objective

The objective of this assignment is to understand the basic workflow of a deep learning project, including:

- Loading a sample dataset
- Exploring the dataset
- Checking for missing values
- Separating input features and target labels
- Normalizing the input data
- Splitting the dataset into training and testing sets
- Building a basic neural network using TensorFlow/Keras
- Training and evaluating the model
- Visualizing the distribution of the dataset

## Dataset

The **Digits dataset** from `sklearn.datasets` is used in this assignment.

The dataset contains handwritten digit images representing numbers from **0 to 9**.

### Dataset Details

- Number of samples: 1797
- Number of features: 64
- Number of classes: 10
- Classes: 0 to 9
- Image size: 8 × 8 pixels
- Each image is represented using 64 pixel values.
